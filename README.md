# Wopflix

Issue tracker for Wopflix — my self-hosted movie and TV server.

This repository holds no code. It exists so that people using Wopflix can report
what's broken and ask for what's missing, in one place I can actually track.

## Opening an issue

- **Something's broken** → [report a bug](../../issues/new?template=bug_report.yml)
- **Something's missing** → [request it](../../issues/new?template=feature_request.yml)

Please don't put passwords, invite links or account details in an issue. If an
issue needs that, I'll reach out directly.

Bugs get looked at in order of how many people hit them. "Me too" comments on an
existing issue are useful; duplicates get closed into the original.
